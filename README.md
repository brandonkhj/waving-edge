# Waving Edge Venture

Marketing site for Waving Edge Venture — a digital solutions company focused on
lean, MVP-first software development.

Live at [wavingedge.com](https://www.wavingedge.com/).

## Stack

- [Vite](https://vitejs.dev/) + [React](https://react.dev/)
- Plain CSS with design tokens (no framework)
- Deployed to GitHub Pages via Actions on every push to `main`

## Development

```bash
npm install
npm run dev      # local dev server
npm run build    # production build to dist/
```
